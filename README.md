# Менеджер задач на React

Учебный проект по изучению React, React Router и Vite

Проект представляет собой функциональный таск-менеджер с поддержкой нескольких списков, подзадач, кастомной фильтрации, поиском и адаптивной темной/светлой темой.

## Возможности

*   Управление списками: создание, переименование и удаление нескольких независимых списков задач.
*   Продвинутые задачи: поддержка подзадач, автоматический расчет прогресса выполнения и отдельная детальная карточка для каждой задачи.
*   Синхронизация с URL: фильтрация (все, активные, выполненные) сохраняется в адресной строке.
*   Умный поиск: регистронезависимый поиск с задержкой (Debounce) 300 мс для оптимизации производительности.
*   Кастомизация: светлая и тёмная темы с сохранением пользовательского выбора между сессиями.
*   Собственные хуки: реализованы `useDebounce`, `useLocalStorage`, `usePageFocus`.

---

### Принятые технические решения
1.  **Структура данных:** подзадачи хранятся внутри объекта родительской задачи в массиве `subtasks`.
2.  **Связи:** связь задачи со списком осуществляется через внешний ключ `listId`. При удалении списка каскадно удаляются все связанные с ним задачи.
3.  **Оптимизация рендеринга:** при смене текущего списка компонент страницы полностью пересоздаётся с помощью атрибута `key={listId}`, что позволяет автоматически сбросить состояние поиска.
4.  **Доступность (a11y):** для подтверждения удаления списка используется нативный тег `<dialog>`, который удерживает фокус внутри модального окна и закрывается по клавише Escape.

## Перенос с Л2

При переходе на React из кода Л2 были удалены следующие части:
*   Прямые манипуляции с DOM (`querySelector`, `appendChild`, `replaceChildren`) — теперь интерфейс описывается декларативно.
*   Шаблоны `<template>` и ручное клонирование узлов — заменены на переиспользуемые React-компоненты.
*   Модуль `view.js` — функция `render` больше не нужна, React сам вызывает компоненты при изменении состояния.
*   Ручное делегирование событий — заменено передачей обработчиков через `props` в JSX.
*   Ручное управление `localStorage` — вынесено в `useEffect` внутри `TodoProvider` и кастомный хук `useLocalStorage`.
