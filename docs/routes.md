# Карта маршрутов

| Адрес | Что показывает |
|---|---|
| `/` | Стартовая страница: переход к первому списку или предложение создать список |
| `/lists/:listId` | Список задач: форма добавления, фильтры, поиск, задачи |
| `/lists/:listId?filter=active` | Тот же список с выбранным фильтром |
| `/lists/:listId/tasks/:taskId` | Карточка задачи поверх списка или рядом с ним |
| `*` | Страница «не найдено» со ссылкой на стартовую |

# Модель данных

```js
{
  lists: [
    { id: 'uuid', title: 'Работа' }
  ],
  tasks: [
    {
      id: 'uuid',
      listId: 'uuid', // связь со списком
      title: 'Сделать отчет',
      body: 'До пятницы',
      done: false,
      createdAt: 1678888888,
      subtasks: [
        { id: 'uuid', title: 'Собрать данные', done: true }
      ]
    }
  ]
}
