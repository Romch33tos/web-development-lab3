# Таблица сценариев ручной проверки

| № | Действие | Ожидаемый результат | Результат |
|---|---|---|---|
| 1 | Создать список «Работа» | Список появился в панели, открыт, адрес содержит его идентификатор | |
| 2 | Добавить задачу в «Работа», перейти в другой список | Задача видна только в «Работа», счётчики списков верны | |
| 3 | Открыть карточку задачи, выбрать фильтр «Активные», перезагрузить страницу | После перезагрузки открыта та же карточка, фильтр сохранён | |
| 4 | Открыть адрес с несуществующей задачей | Сообщение «Задача не найдена» и ссылка на список | |
| 5 | Открыть адрес `/abc` | Страница «не найдено» со ссылкой на стартовую страницу | |
| 6 | Добавить три подзадачи, отметить две | В карточке «Выполнено 2 из 3», в строке задачи 2/3 | |
| 7 | Очистить название задачи в карточке и уйти с поля | Пустое название не сохранено | |
| 8 | Быстро набрать в поиске «отчёт» | Список меняется один раз после паузы, а не на каждую букву | |
| 9 | Найти несуществующее слово, нажать «Сбросить поиск» | Показано сообщение с запросом, после сброса видны все задачи | |
| 10 | Ввести запрос, перейти в другой список | Поле поиска пустое | |
| 11 | Включить тёмную тему, перезагрузить страницу | Тёмная тема без мигания светлой | |
| 12 | Удалить открытый список с подтверждением | Список и его задачи удалены, открыта стартовая страница | |
| 13 | Открыть подтверждение удаления, нажать Escape | Окно закрыто, список не удалён, фокус на кнопке удаления | |
| 14 | Перейти в другой список клавиатурой | Фокус на заголовке открытого списка | |
| 15 | Перезагрузить страницу на вложенном адресе (карточка задачи) | Приложение открывается, ошибки 404 нет | |
| 16 | Ввести пустой заголовок задачи и отправить форму | Задача не добавлена, показано сообщение об ошибке | |
| 17 | Ввести в название задачи HTML-теги (`<b>текст</b>`) | Текст отображается как текст, разметка не выполняется | |
| 18 | Проверить ширину 360px | Нет горизонтальной прокрутки, боковая панель и карточка удобны | |
| 19 | Пройти основные действия без мыши (Tab, Enter, Space) | Все операции доступны, фокус виден | |
| 20 | Открыть произвольный несуществующий адрес | Показана страница «не найдено» | |
